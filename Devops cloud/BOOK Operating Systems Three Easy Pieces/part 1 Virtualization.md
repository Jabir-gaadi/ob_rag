Virtualisation : ^Rssni2wn

1. What is Virtualization?
Virtualization is a technique used by the Operating System (OS) to make a single physical resource appear as multiple virtual resources. ^EJSpnMA5

2. Physical Resources vs. Virtual Resources
A physical resource is an actual hardware component, while a virtual resource is an abstraction created and managed by the Operating System. ^vsY30Xs8

الـ Virtualization هي تقنية كيستعملها الـ Operating System باش يخلي واحد الـ Physical Resource (مورد حقيقي فالحاسوب) يبان لعدة Programs بحال إلا كل واحد فيهم عندو Resource خاص بيه.

مثلاً، إلا كان عندنا CPU واحد، والـ Computer فيه 5 ديال الـ Programs خدامين، الـ OS يقدر ينظم استعمال هاد الـ CPU باش كل Program تقدر تخدم، وكيبان ليها بحال إلا عندها CPU خاص بها.

ولكن فالحقيقة، هاد الـ Programs كاملين كيتقاسمو نفس الـ Physical CPU. ^hBcdKHkY

خاصك تعرف الفرق بين جوج مفاهيم:
- Physical Resource: هو الـ Hardware الحقيقي اللي موجود فالحاسوب، بحال CPU أو RAM.
- Virtual Resource: هو واحد الـ Abstraction (تمثيل مجرد) كيقدمها الـ OS للـ Programs باش يخليها تستعمل الموارد بلا ما تتعامل مباشرة مع طريقة تقاسم الـ Hardware.
مثلاً، الـ Physical CPU هو المعالج الحقيقي، أما الـ Virtual CPU فهاد السياق فهو التصور اللي كيقدمو الـ OS للـ Program باش تقدر تنفذ التعليمات ديالها وكأن عندها CPU متاح ليها. ^8Cn5jCFr

3. CPU Virtualization
CPU virtualization allows multiple programs to share a physical CPU while giving each program the illusion that it has its own CPU. ^sulPS3tD

4. Time Sharing
Time sharing is a technique in which the OS switches the CPU between different running programs, allowing them to make progress over time. ^QtF3q6fu

5. The Illusion of Dedicated Resources
Virtualization creates the illusion that each program has its own dedicated hardware resources, even though those resources may be shared. ^BsozyiSJ

Virtualization is a fundamental OS technique that abstracts physical hardware resources and makes them appear as virtual resources to programs. In CPU virtualization, the OS allows multiple programs to share a physical CPU through mechanisms such as time sharing and scheduling, creating the illusion that each program has its own CPU. ^MzkH9qZl

The Abstraction: The Process : ^TmMzIdnK

1. What is a Process?
A process is a program in execution (a running instance of a program). It is one of the most fundamental abstractions provided by the Operating System. ^PTnoX6xx

2. Program vs. Process
A program is a passive collection of instructions and static data stored on disk. A process is the active execution of those instructions, managed by the OS. ^RL4mDFVK

3. CPU Virtualization
CPU virtualization allows the OS to create the illusion of many virtual CPUs, even though the system has only a limited number of physical CPUs. ^J8vuManc

4. Time Sharing
Time sharing is a technique in which the OS allows multiple processes to share a CPU by running one process for a period of time, then switching to another. ^bFGMgMRf

5. Performance Cost of Time Sharing
Time sharing enables concurrent execution of multiple processes, but sharing a limited CPU resource can reduce the performance of individual processes. ^gSIVvIO1

6. Time Sharing vs. Space Sharing
Time sharing divides access to a resource over time, while space sharing divides a resource into portions allocated to different users or processes. ^Pjz3jEfA

7. OS Mechanisms
Mechanisms are low-level methods that implement OS functionality. A key example is context switching, which allows the OS to stop one process and resume another on the CPU. ^OuocmybU

8. OS Policies
Policies are algorithms that determine which decisions the OS should make. A CPU scheduling policy decides which ready process should run next. ^EtpLmvqX

9. Mechanisms vs. Policies
Mechanisms define how an operation is performed, while policies determine what decision should be made. ^vSp5KZ4x

هادي من أهم القواعد اللي خاصك تفهم فـ Operating Systems:
- Mechanism = How? كيفاش غادي ننفذ العملية؟
- Policy = Which/When? شكون نختار وفاش ندير العملية؟
مثلاً، الـ Scheduling Policy كتقرر أن P2 هي اللي خاصها تستعمل الـ CPU دابا، والـ Context Switching Mechanism كتساعد الـ OS ينفذ التبديل من P1 لـ P2.

يعني الـ Policy كتقرر، والـ Mechanism كينفذ. ^zlXcwnHz

1. Process and Machine State
A process is a running program, and its execution can be described by its machine state. ^wtgBs6fQ

2. Address Space
A process's address space is the range of virtual memory addresses it can access, including memory used for its instructions and data. ^3XJ0b37t

3. CPU Registers
CPU registers are part of a process's machine state because instructions read and modify their values during execution. ^4RLrkIGD

4. Program Counter (PC)
The Program Counter (PC), also called the Instruction Pointer (IP), is a register that identifies the next instruction to execute. ^oXOZ10PA

5. Stack Pointer (SP) and Frame Pointer (FP)
The Stack Pointer (SP) and Frame Pointer (FP) are registers used to manage the call stack, which stores function-related information such as local variables, parameters, and return addresses. ^qb4iBIfv

الـ Stack هو جزء من الـ Memory كيتستعمل باش ننظمو معلومات استدعاء الـ Functions.

عندنا جوج Registers مهمين:
- Stack Pointer (SP): كيشير للموقع الحالي ديال الـ Stack Top.
- Frame Pointer (FP): كيستعمل، فبعض الـ Architectures وCalling Conventions، كمرجع ثابت نسبياً داخل الـ Stack Frame ديال الـ Function الحالية.
مثلاً، ملي Function كتعيط لـ Function أخرى، كيقدر يتنشأ Stack Frame جديد فيه معلومات بحال Local Variables وReturn Address.

الـ Return Address كيساعد التنفيذ يرجع للبلاصة الصحيحة من بعد ما تسالي الـ Function.

ملاحظة: استعمال الـ Frame Pointer ماشي إجباري فكل البرامج؛ بعض الـ Compilers يقدرو يستغناو عليه. ^dRXen8uR

6. I/O State and Open Files
A process's state also includes I/O-related information, such as the files it currently has open. ^giR1p2Dp

7. Separate Policy and Mechanism
Operating systems separate policies from mechanisms: mechanisms define how an operation is performed, while policies determine which action should be taken. This separation improves modularity and flexibility. ^5Fv6zn8R

4.2 Process API ^a8w98cKa

1. What is a Process API?
A Process API is an interface provided by the Operating System that allows programs to create, manage, monitor, and terminate processes. ^eMZZ2R8B

2. Essential Process API Operations
Modern Operating Systems provide five essential categories of process operations: Create, Destroy, Wait, Miscellaneous Control, and Status. ^JrxCTVBU

الشرح بالدارجة:

هادو أهم العمليات اللي خاصك تعرف:

                    Create   =     Create a new process
                                            Destroy    =    Forcefully terminate a process
                              Wait     =   Wait for a process to finish
                                         Control    =    Suspend or resume a process
                                        Status    =    Retrieve information about a process

مثلاً فـ Linux:
- fork() كتخلق Process جديدة.
- wait() كتسمح لـ Parent Process تسنى حتى يسالي واحد من الـ Child Processes ديالها.
- kill() كتبعث Signal لـ Process، وممكن هاد الـ Signal يسبب فـ Termination ديالها.
- ps كيعرض معلومات على الـ Processes.
ملاحظة: هادو أمثلة من UNIX/Linux، ماشي أسماء موحدة لجميع Operating Systems. ^tGeNR3B3

3. Loading a Program into Memory
To create a process, the OS must set up its address space and make the program's executable code and static data available in memory. ^COuZRIUy

الـ OS كيبدا عملية إنشاء وتشغيل Process ديال هاد البرنامج.
الـ Code والـ Static Data كيوليو مرتبطين بالـ Address Space ديالها.
ولكن ماشي ضروري جميع الـ Bytes ديال البرنامج يتحمّلو مباشرة للـ Physical RAM، وهادشي غادي نفهموه فالنقطة التالية. ^zgamvemk

4. Eager Loading vs. Lazy Loading
Eager loading loads the required program contents into memory before execution, while lazy loading brings code and data into physical memory only when needed. ^j0VQxqwn

كاينين جوج Approaches مختلفين لتحميل الـ Program:

Eager Loading: الـ OS كيحمّل المحتوى المطلوب كامل قبل ما يبدا التنفيذ.

Lazy Loading: الـ OS كيقدر يوجّد Mapping ديال البرنامج، ولكن يأجل تحميل بعض الأجزاء للـ Physical RAM حتى تحتاجهم الـ Process.

مثلاً، عندك Program فيه بزاف ديال الـ Functions، ولكن استعملتي غير بعضها.

باستعمال Lazy Loading، ماشي ضروري جميع الـ Pages ديال الـ Code يكونو محمّلين فالـ RAM من الأول.

فـ Modern OS، هاد العملية كتكون مرتبطة بمفاهيم بحال Demand Paging وPage Faults.

Important: Lazy Loading كتعاون على تحسين استعمال الـ Memory وتجنب تحميل أجزاء مازال ما محتاجينهاش. ^vOkqvQs6

5. Stack Allocation
The OS sets up a run-time stack for the new process. The stack is used for function calls, local variables, parameters, and return addresses. ^LCS267UT

Related concepts to study later: Demand Paging, Page Faults, Virtual Memory, fork(), exec(), وProcess Lifecycle. ^a94ifnJs
