An end system (or host) is a device connected to a network that can send or receive data. ^8Q0MbYIi

- Network Interface (NIC): باش يتصل بالشبكة.

Communication Links : ^cHweqlVy

A communication link is a medium that carries data between network devices. ^thiugTDP

كل Link عندو Capacity ديال Transmission، غالباً كنعبرو عليها بـ:

R = bits per second (bps)


مثلاً واحد Ethernet Link ممكن تكون عندو Rate ديال 1 Gbps.

ولكن خاص تفرق بين جوج Concepts:
- Bandwidth / Link Rate: شحال يقدر Link ينقل نظرياً فالثانية.
- Throughput: شحال من Data فعلياً كتوصلك فالثانية.
ماشي ضروري يكونو متساويين. Throughput يقدر ينقص بسبب Congestion, Protocol Overhead, Packet Loss أو Limitations ديال Links آخرين.

وهنا كاينة نقطة مهمة: Transmission Rate ماشي هي Latency. الأولى كتتعلق بالكمية ديال Bits اللي كتمشي فالثانية، والثانية بالوقت اللي كتحتاجو Data باش توصل. ^ho1T03i0

كيفاش كيخدم: الـ link عندو حد فيزيائي (الكابل، الـ Wi-Fi، الـ fiber...) أو حد من الـ ISP. إلا كان عندك 100 Mbps، ماغاديش يمكن ليك تدز أكثر منو، حتى لو الجهاز ديالك قادر. ^DQA19TSO
